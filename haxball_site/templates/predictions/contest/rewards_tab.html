Распределение наград

В каждом туре участники имеют возможность заработать CIS Coins (CC) - виртуальную валюту, которая в дальнейшем может быть использована для приобретения различных услуг на сайте.

Как формируются награды
  1. За каждого активного участника в общий призовой фонд тура добавляется {{ selected_tournament.prize_pool_contribution|floatformat:0 }} CC
    2. {% if selected_tournament.scoring_method == 'coefficients' %}
  2. 50% фонда делятся поровну между всеми участниками тура
  3. 50% фонда делятся между участниками с положительным балансом за тур пропорционально весу места
    w = 1 / √place (1-е место — вес 1, 2-е — 1/√2, 3-е — 1/√3 и так далее).
    При равенстве очков места делят суммарный вес поровну
    4. {% else %}
  4. Призовой фонд тура распределяется между всеми участниками пропорционально заработанным ими очкам
    5. {% endif %}
  5. Начисление наград происходит раз в неделю (при условии, что все матчи тура уже были сыграны)

Пример расчета

Допустим, в туре приняли участие 5 человек:

  • Участник A: 10 очков
  • Участник B: 8 очков
  • Участник C: 6 очков
  • Участник D: 4 очка
  • Участник E: 2 очка

Призовой фонд: 5 × {{ selected_tournament.prize_pool_contribution|floatformat:0 }} = {{ pool|floatformat:2 }} CC

Общие очки: 10 + 8 + 6 + 4 + 2 = 30 очков

Награды:

  • Участник A: (10/30) × {{ pool|floatformat:2 }} = {{ pool|mul:10|div:30|floatformat:2 }} CC
  • Участник B: (8/30) × {{ pool|floatformat:2 }} = {{ pool|mul:8|div:30|floatformat:2 }} CC
  • Участник C: (6/30) × {{ pool|floatformat:2 }} = {{ pool|mul:6|div:30|floatformat:2 }} CC
  • Участник D: (4/30) × {{ pool|floatformat:2 }} = {{ pool|mul:4|div:30|floatformat:2 }} CC
  • Участник E: (2/30) × {{ pool|floatformat:2 }} = {{ pool|mul:2|div:30|floatformat:2 }} CC
